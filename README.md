# CVForge

CVForge is a web application designed to help users create professional CVs with potential AI assistance and connect with recruiters.

## Technology Stack

The application is built using:

- **Frontend:** Next.js and React for building the user interface.
- **Backend:** Firebase for various backend services, including:
    - **Authentication:** For managing user accounts and sessions.
    - **Firestore:** A NoSQL database for storing user profiles, CV data, and other application information.
    - **Hosting:** For deploying and serving the web application.

## User Roles

The application supports two main user roles:

- **Creator:** Users who build and manage their professional CVs.
- **Recruiter:** Users who can search and view CVs using a unique code provided by creators.
