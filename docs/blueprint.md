# **App Name**: CVForge

## Core Features:

- Personal Info Input: Allow users to input personal information, including name, title, contact details, and links to online profiles.
- Experience Management: Enable users to add, edit, and organize work experience entries with details like job title, company, dates, and responsibilities.
- Education Input: Provide an interface for users to input education details, including degrees, institutions, dates, and relevant notes.
- Live CV Preview: Offer a dynamic preview panel that updates in real-time as users input and modify their CV data, reflecting the changes instantly.
- AI-Powered Language Enhancement: Generative AI powered tool, providing users with suggestions for improving the language used in their resume sections, offering options for rephrasing bullet points and summary statements.

## Style Guidelines:

- Primary color: Dark blue (#2c3e50) for a professional and trustworthy look.
- Secondary color: Light gray (#ecf0f1) for backgrounds and neutral elements.
- Accent: Teal (#3498db) for interactive elements and highlights.
- Clean and readable sans-serif fonts for headings and body text.
- A split-screen layout with input forms on the left and a live preview on the right.
- Use simple, consistent icons from Material Icons for common actions and section headers.
- Subtle transitions and animations for a polished user experience (e.g., when adding or deleting entries).
